Returning a full HTML document instead would confuse the swap (HTMX would inline the response body inside the target, duplicating the navbar and the outer wrapper every click — the exact bug this split fixes). Every interactive control in this partial carries `hx-get` / `hx-target="#reports-charts"` / `hx-push-url="true"`, plus a plain `href` / `action` as the no-JS fallback. With HTMX loaded the swap goes through and the URL updates without a full page load; without it the same link is a normal GET that renders the full reports page. The instrument charts share one period filter. Their drill-down values are stable typed IDs rather than display labels. Design tokens (PRD §9.1): the `tone` values coming out of charts.py are mapped to Tailwind classes here so the design system stays in the template layer; the only literal color values are inside SVG stops for the primary indigo→fuchsia stroke (Tailwind utility classes do not apply to SVG stroke attributes). See the docstring at the top of `dashboard/reports.html` for the broader conventions this partial inherits. {% endcomment %}
