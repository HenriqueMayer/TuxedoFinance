Returning a full HTML document instead would confuse the swap (HTMX would inline the response body inside the target, duplicating the navbar and the outer wrapper every click — the exact bug this split fixes). Every period control in this partial carries `hx-get` / `hx-target="#reports-charts"` / `hx-push-url="true"`, plus a plain `href` / `action` as the no-JS fallback. With HTMX loaded the swap goes through and the URL updates without a full page load; without it the same link is a normal GET that renders the full reports page. Chart marks select values directly without navigation. Ctrl-hover composition uses signed scopes containing stable record IDs rather than display labels.
