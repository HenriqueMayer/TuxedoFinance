{% load i18n %} {% comment %} Reusable theme toggle button (Final Design System §0/§3). A circular icon button marked with `data-theme-toggle`; static/js/theme.js wires every instance. The FOUC inline script in base.html already set `.dark` on before this paints, so the right icon is shown on first render with no flash. The two SVG icons take turns via Tailwind's `dark:` variant: the moon shows on the light surface (offering "switch to dark"), the sun shows on the dark surface. The `aria-label` is the same either way — the toggle isn't labelled "toggle to dark"/"toggle to light" because that depends on the current state, and the icon itself communicates the affordance. {% endcomment %}
