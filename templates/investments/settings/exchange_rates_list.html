{% extends 'base.html' %} {% comment %} Exchange rates (Investments → Settings → Exchange rates). The user manages manual FX rates that the Investments list page uses to convert foreign-currency balances into the base currency for the simulated total. Rates are append-only: if a rate moves, the user adds a new row with a newer `effective_date`; the old one stays put for history. The page shows the user's rates grouped by `from_currency`, the most recent per pair on top of each group and older rows collapsed into a `
` history. Delete is always a POST from the confirm screen. Below the list, the create form is inlined so the user can add a new pair (or a new effective date for an existing one) without leaving the page. The form's `to_currency` is disabled — it is always the project base, by design. {% endcomment %} {% block title %}Exchange Rates — CashFlow{% endblock %} {% block content %} {% url 'investments:list' as investments_url %}
