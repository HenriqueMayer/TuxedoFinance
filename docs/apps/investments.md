# `investments`

The investments app is a separate manual portfolio ledger. It does not
reference `Transaction`: a dashboard `Transaction` of type `INVESTMENT` and a
matching portfolio operation are intentionally kept in sync by the user.

## Domain

```text
Institution (bank, broker, exchange)
└── InvestmentProduct (Cofrinho Henrique, CDI, CDB)
    └── Asset (BRL, USD, BTC, ETF, or another user-defined code)
        └── Investment operation
```

An operation is one of three kinds:

- `DEPOSIT` — capital added by the user.
- `WITHDRAWAL` — money removed from the product.
- `YIELD` — a manual return generated by the product.

The balance of an asset is `deposits + yields - withdrawals`. Yields are never
merged into deposits, so the screen and charts can distinguish user capital
from investment growth.

## Automatic yield placeholder

Products currently use manual yields only. The model contains `MANUAL`,
`MONTHLY`, and `ANNUAL` yield-mode choices so the future direction is explicit,
but the product form only permits `MANUAL`. Monthly and annual calculations are
not performed and are shown in the list as `Coming soon`.

## User flow

1. Create a bank or broker.
2. Create an investment product under that institution.
3. Create one or more free-form assets.
4. Record a deposit, withdrawal, or manual yield.

The operation form scopes product and asset choices to the logged-in user. The
list can be filtered by institution, product, asset, operation type, and text.
Legacy rows without the new product/asset links are ignored by the new screen;
they are not migrated or deleted.

## Charts

- **Investment evolution** shows the cumulative portfolio total converted to
  the configured base currency when a usable exchange rate exists.
- **Monthly flow** shows separate deposits, withdrawals, and yields.

Both charts remain server-rendered SVG and use the existing HTMX partial-swap
pattern. Free-form asset codes without a configured exchange rate are surfaced
as missing rather than silently included in a converted total.

## Exchange rates

`ExchangeRate` remains a manual, append-only table for supported currency pairs
whose target is the project base currency. Free-form assets can be recorded and
shown in their native code; automated pricing for arbitrary assets is outside
the current scope.
